## The entry

> My fitness tracker congratulated me on 10,000 steps, then admitted 9,000 of them were just me pacing the kitchen waiting for a text back.

## How it works

`main.ts` writes the one-liner above, verbatim, to `/output/entry.txt`.
The text is a fixed constant, so every run produces byte-identical output.
No network, no secrets, no external input.

Run it with:

```sh
node main.ts
```
